# Task Manager

A full-stack task management application where users can create, update, and manage their daily tasks.

## Live Link
https://task-manager-six-lime.vercel.app/

## Tech Stack

Frontend
- React.js
- JavaScript
- HTML
- CSS

Backend
- Node.js
- Express.js

Database
- SQLite

## Features

- User registration and login
- Create tasks
- Update tasks
- Delete tasks
- View all tasks
- Simple dashboard to manage tasks

## Setup

### Clone the repository

```
git clone https://github.com/suraj-tetarwal/task-manager.git
```

## Setup Backend

```
cd backend
npm install
node server.js
```

## Setup Frontend

```
cd frontend
npm install
npm start
```
